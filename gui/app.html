گزارش سرعت صفحات

۱ورودی

در فایل CSV لازم نیست آدرس در ستون اول باشد — خودش ستونی را که آدرس است پیدا می‌کند و سرصفحه را رد می‌کند.
فرزندانش لیست می‌شوند تا انتخاب کنی کدام‌ها تست شوند.
سقف را روی all بگذار تا همه‌ی آدرس‌ها تست شوند.

۲نتایج
روی سرستون کلیک کن تا مرتب شود. پیش‌فرض: بدترین نمره بالا.

تنظیمات

کلید را از کجا بگیرم؟
  1. یک پروژه بساز (اگر نداری).
  2. PageSpeed Insights API را Enable کن.
  3. Chrome UX Report API را هم Enable کن (برای گزینه‌ی CrUX).
  4. Credentials → Create credentials → API key.
  5. در Application restrictions گزینه‌ی None را نگه دار — اگر روی HTTP referrers یا IP بگذاری، درخواست سرور‌به‌سرور رد می‌شود.
کلید فقط روی همین کامپیوتر ذخیره می‌شود و هیچ‌جا فرستاده نمی‌شود جز خودِ گوگل.
