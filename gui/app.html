Where do I get a key?
  1. Create a project, if you have none.
  2. Enable the PageSpeed Insights API.
  3. Enable the Chrome UX Report API as well, for the CrUX option.
  4. Credentials → Create credentials → API key.
  5. Leave Application restrictions on None. Setting HTTP referrers or IP addresses rejects a server-to-server call.
The key is stored on this computer only, and is sent nowhere but Google.
